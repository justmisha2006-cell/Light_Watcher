# ⚡ Light Watcher v2.2

**Розумний ESP32-модуль для автоматичного моніторингу наявності електромережі та сповіщення у Telegram**

![Version](https://img.shields.io/badge/version-2.2-blue.svg)
![Platform](https://img.shields.io/badge/platform-ESP32--C3-green.svg)
![License](https://img.shields.io/badge/license-MIT-orange.svg)

**Light Watcher** — це прошивка для мікроконтролерів ESP32 (з оптимізацією під ESP32-C3), яка відстежує стан напруги в мережі та миттєво надсилає сповіщення про вимкнення та ввімкнення світла у Telegram (особисті повідомлення, групи та конкретні топіки/гілки).

---

## 🌟 Основні можливості

* 🌐 **Multi-WiFi підтримка**: Налаштування основної та резервної мережі Wi-Fi. Якщо основна мережа недоступна, пристрій автоматично переключиться на резервну.
* 📲 **Гнучка система сповіщень Telegram**:
  * Надсилання повідомлень власнику.
  * Підтримка до **2-х Telegram-груп**.
  * Підтримка **супергруп з топіками (Topics / message_thread_id)**.
* ⏱ **Точний облік часу та тривалості**:
  * Фіксація часу вимкнення та ввімкнення електроенергії.
  * Автоматичний розрахунок тривалості відсутності світла та часу, скільки світло було в наявності.
  * Автоматична синхронізація часу через NTP (з підтримкою переходів Зима/Літо для України).
* ⚙️ **Зручний Web-інтерфейс (Captive Portal)**:
  * Початкове налаштування через власну точку доступу `Light-Watcher-Setup`.
  * Немає потреби «жорстко» прописувати паролі в коді.
* 🛡 **Надійність та відмовостійкість**:
  * Вбудована фільтрація аналогового сигналу (**Smart Debounce**) для виключення хибних спрацьовувань від стрибків напруги.
  * Апаратний сторожовий таймер (**Hardware Watchdog WDT**) для захисту від зависань.
  * Буферизація пропущених повідомлень при тимчасовій втраті зв'язку.
* 🔄 **Бездротове оновлення (ArduinoOTA)**: Можливість оновлювати прошивку пристрою по Wi-Fi без підключення кабелю.

---

## 🛠 Обладнання та компоненти

1. **Мікроконтролер**: ESP32-C3 (наприклад, ESP32-C3 SuperMini або Dev Module).
2. **Детектор наявності мережі**:
   * Оптопара / модуль детекції напруги 220В (з виходом на ADC/Digital).
   * Або блок живлення 5V, підключений до дільника напруги на підключений пін (`GPIO 3`).
3. **Джерело резервного живлення**: Li-Ion акумулятор / PowerBank / UPS для забезпечення роботи ESP32 під час відсутності мережі 220В.

---

## 📌 Призначення пінів (Pinout)

| Пін ESP32-C3 | Призначення | Опис |
| :--- | :--- | :--- |
| **GPIO 3** | `readPin` | Аналоговий вхід (ADC1) для зчитування стану мережі |
| **GPIO 9** | `Reset Config` | Вхід кнопки скидання (при замиканні на GND під час старту запускається Web AP) |

## ⚙️ Налаштування перед прошивкою в Arduino IDE

Для успішної компіляції та завантаження прошивки в середовищі Arduino IDE оберіть такі налаштування:

1. **Плата (Board)**: `"ESP32C3 Dev Module"`
2. **USB CDC On Boot**: `"Enabled"` *(Обов’язково для роботи Serial Monitor через USB)*
3. **Partition Scheme**: `"Minimal SPIFFS (Large APPS with OTA)"` *(для використання OTA)* або `"Huge APP (3MB No OTA/1MB SPIFFS)"`
4. **Решта налаштувань**: за замовчуванням.

### Необхідні бібліотеки
Переконайтеся, що у вас встановлені наступні бібліотеки:
* `WiFi.h` (вбудована в ядро ESP32)
* `Preferences.h` (вбудована)
* `ArduinoJson` (v6 або v7)
* `UniversalTelegramBot`
* `ArduinoOTA` (вбудована)

## 🚀 Перший запуск та налаштування

1. Завантажте прошивку в мікроконтролер.
2. При першому включенні (або якщо мережа Wi-Fi недоступна) пристрій створить точку доступу Wi-Fi з назвою: **`Light-Watcher-Setup`**.
3. Підключіться до цієї мережі зі смартфона або ПК. Автоматично відкриється сторінка конфігурації (або перейдіть за адресою `192.168.4.1`).
4. Введіть необхідні дані:
   * **SSID та пароль** основної та (за бажанням) резервної мережі Wi-Fi.
   * **Bot Token** вашого Telegram-бота (отриманий через `@BotFather`).
   * **Chat ID** власника (ваш особистий ID, дізнатися можна через `@userinfobot`).
   * **ID груп та топіків** (якщо плануєте розсилку в групи).
5. Натисніть **«ЗБЕРЕГТИ ТА ПЕРЕЗАПУСТИТИ»**. Пристрій збереже дані в енергонезалежну пам’ять (NVS) і перезавантажиться.

## 🤖 Команди Telegram-бота

### Основні команди:
* `/start` або `/help` — Довідка та панель керування.
* `/status` — Поточний стан електромережі, час роботи, рівень Wi-Fi, IP-адреса та системний час.
* `/info` — Інформація про систему та версію прошивки.

### Налаштування часових поясів:
* `/set_time_auto` — Автоматична синхронізація часу через NTP (UTC+2 взимку / UTC+3 влітку).
* `/set_winter_time` — Фіксований зимовий час (UTC+2).
* `/set_summer_time` — Фіксований літній час (UTC+3).

### Тестування сповіщень:
* `/test_off` — Імітація сповіщення про вимкнення світла у всі чати.
* `/test_on` — Імітація сповіщення про ввімкнення світла у всі чати.
* `/test_groups` — Перевірка зв’язку та відправки повідомлень у налаштовані групи/топіки.

### Системні команди:
* `/restart` — Дистанційне перезавантаження пристрою.
* `/clear_data` — Повне скидання збережених налаштувань та перехід у режим Web AP.
